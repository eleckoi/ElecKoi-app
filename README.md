<h1 align="center">电子爱</h1>

<p align="center">

电子爱是一个由 DSH Agent 驱动的 AI 角色卡创作与演绎客户端，首先提供免费开源的 Android 版本，随后开发 PC 客户端。

## 核心亮点

**像 vibe coding 一样创作角色。** 你只需要说出想法，剩下那些曾经最繁琐的写卡工作，可以交给 Agent 和工具一步步完成。

- **会自己查设定的角色 Agent**：DSH 让角色拥有真正的 Agent 能力。它会像查资料一样主动搜索设定库，只读取当前剧情需要的内容，再调用变量、联网和其他工具继续演绎。
- **从手工写卡到 Agent 创作**：创作 Agent 可以搭建和修改角色、设定库、变量、正则与形象素材；所有修改先预览、校验，再由创作者决定是否保存。
- **用工具调用稳定更新变量**：Agent 不在回复里输出特定的变量更新格式，而是调用专用工具读取、校验并更新关系、物品、事件和世界状态。每类工具都有明确的数据格式和操作规范，减少模型输出漂移，让状态演进更稳定、可追踪；角色还可以带有自己的 HTML、CSS、JavaScript 和素材，把状态呈现为可交互的演绎界面。

电子爱想建立一个持续进化的创作飞轮：把社区积累的角色设计知识、模板和方法变成 Agent 可以检索和复用的能力。知识越丰富，Agent 越会创作；创作出的作品与经验，又能继续推动整个社区向前发展。

## 为什么做电子爱

电子爱不只是一个 AI 聊天软件。

我希望“AI 角色扮演设计师”能够成为一种真正被看见、被尊重，也能够获得合法收入的新兴职业。优秀的角色作品也应该像小说、游戏和影视作品一样被认真创作、被人记住，让创作者有机会依靠自己的热爱与能力一直走下去。

电子爱的最终目标，就是加速这一职业的诞生与普及。我们会从免费开源的客户端、Agent 创作工具、角色作品的表现能力和创作者生态开始，一步一步把这条路铺出来。无论这个未来还要多久才会到来，电子爱都会先迈出这一步，并始终朝着这个目标走下去。

我们想给所有喜欢 AI 角色扮演的人带来的，不只是一款更好用的软件，而是一条过去并不存在的路。在就业环境充满挑战的今天，让热爱角色、擅长创作的人，多一种值得认真选择的人生可能。

电子爱探索的不只是 AI 角色对话，也包括由 AI 驱动的游戏、互动叙事以及更多尚未被定义的创作形式。如今一些重前端的角色卡已经显现出这种可能：角色不再只是简单的对话，也可以成为界面精美的模拟器游戏，让人亲自经历各种有趣的故事，甚至把曾经只能存在于幻想中的世界，变成可以自由探索的开放世界。电子爱希望和创作者一起，把这些雏形继续发展成更丰富的作品。

电子爱想为这件事提供一套长期开放的工具，也希望聚集同样相信这件事的人。一个人能够做到的事情很有限；如果未来项目拥有收入，我希望能够邀请真正有能力的开发者、设计师和创作者加入，给予他们应得的报酬，一起把这个项目做得更好、更久。

我承诺：电子爱官方发布的 Android 客户端和未来的 PC 客户端将一直保持免费开源，不会转为闭源产品。官方客户端不内置任何付费功能，不内置推荐任何API中转站；用户自主选择并配置自己信任的模型服务。

如果项目未来获得持续收入，目前设想的主要方向是建立面向 AI 角色创作生态的资源与服务平台，帮助创作者展示、发布和交易角色作品、OC 定制、美术素材、界面设计、插件与扩展及其他创作内容与服务，并持续维护自己的作品。平台未来可能通过公开透明的平台服务、赞助或捐赠获得收入，用于基础设施、支付协作者报酬、组建专业团队以及项目长期维护。具体规则将在相关服务上线前公开说明。

我不认为开源必须以开发者和创作者无法获得回报为代价。我希望电子爱最终形成的是一个良性循环：核心工具自由开放，创作者自主决定作品的授权和价格，项目也能获得足以持续开发的资源。

## 内容边界

电子爱是一个开源、本地运行的客户端。项目方不提供模型服务，也没有接收用户本地角色卡、设定或聊天记录的数据后台，无法也不会获取这些隐私数据；用户连接的模型服务由用户自己选择。

未来如果上线设计资源与服务平台，平台将只面向合法合规的设计资源与创作服务，并对平台上公开发布或交易的内容依法管理。

```powershell
.\gradlew.bat :app:assembleDebug
```

仓库已包含 Gradle Wrapper、Android 模块、原生代码、WebView 运行资源，以及构建本地 Runtime 所需的文件。体积较大的 `runtime/bundles/*.egruntime` 不纳入版本控制，构建时会按照固定清单自动准备。
